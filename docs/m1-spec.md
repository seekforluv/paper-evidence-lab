# M1: 可复现的 SciFact 检索评测

目标：把 BM25 原型接到独立标准检索数据，报告真实 nDCG@10、Recall@10 和逐查询结果。软件工程演示种子与 SciFact 分开；检索标签不是科学结论真假判决。

固定数据：官方 BEIR scifact.zip，以官方 MD5 与本次获取 SHA-256 双重核对；原始包、摘要、查询文本和 qrels 放 data/local/。固定测试集，仅按 test qrels 选查询，不使用 train 或其余 queries 调参。数据来源/许可分别记录。

固定方法：沿用 M0 小写 ASCII 分词、明确停用词、不词干化、Lucene BM25 k1=1.5 b=.75。引入可复用纯文本排序核心；M0 search 保持 top-k 1–5，评测通过独立接口取10条。按全体正分候选 score 降序/doc_id 升序截断，无零分填充；排除 query/doc 同 ID 与 BEIR 默认一致。

固定指标：标准 trec_eval 线性相关性增益 DCG（rel/log2(rank+1)），理想排序归一化；Recall 为前10条正相关文献数/该查询全部正相关文献数。以 test qrels 的全部查询作宏平均，缺检索结果计零；不可遗漏失败/空结果查询。重复检索 ID、未知查询/文献、重复 qrel、负标签和无正相关 qrel 查询报错。

严谨边界：数据/查询/标签 ID 完整性、精确计数、输入文件哈希与配置记录；手算合成 fixture 验证公式，再与独立参考评测器交叉核对。测试只使用原创数据、禁止网络。真实运行与离线单元测试分开。

公开产物：代码、下载清单、命令、指标、逐查询 ID/指标/排序 ID、限于文本来源的错误分析与来源链接。真实摘要/查询原文不上传；不填造性能、准确率或研究结论。逐查询指标查看是本次冻结评测的分析，不再据此修改参数并把同一测试集称为新验证。

完成条件：固定源下载/校验、离线测试、真实300查询运行、独立指标核对、确定性复跑、中文文档与限制、独立代码审查、真实 ZCode 有界审查、GitHub实际CI通过。
