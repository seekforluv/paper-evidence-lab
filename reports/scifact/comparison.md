# Paper Evidence Lab：BM25 与 MiniLM 的冻结检索对比

在本次 **300 条 SciFact 查询**上，BM25 的平均 nDCG@10 高于预先选定的 MiniLM；两者平均 Recall@10 接近。MiniLM 改善了部分查询，但没有在这组平均指标上超过 BM25。模型与参数在首次语义评测前已固定，结果出来后没有再选模型或调参。

| 方法 | nDCG@10 | Recall@10 |
| --- | ---: | ---: |
| BM25 | **0.67246** | **0.78561** |
| MiniLM（ONNX） | 0.64508 | 0.78333 |
| MiniLM − BM25 | −0.02738 | −0.00228 |

这些是本固定样本的描述性结果，未检验统计显著性，也不是事实正确率。nDCG 同时考虑相关文献是否找到及其名次；Recall 衡量已标注相关文献的找回比例。两个方法的原始检索分数尺度不同，不能直接把BM25分数与余弦分数比较。

## 问题、数据与方法

项目考察：在同一小型科学文献基准上，一个简单可追溯的词项模型和一个固定轻量英文句向量模型，各自能找回哪些相关文献。另有两篇AI编程助手论文用于M0功能演示，没有混入基准，也不能从本基准成绩推断该演示问题的科学结论。

官方BEIR SciFact固定快照包含5,183篇文献、1,109条查询文本；只根据test qrels选择300条查询，339对相关性均为1。**BEIR test来自原SciFact公开dev，不是原隐藏测试集。** ZIP和三个输入文件均固定哈希，逐查询覆盖完整。[数据来源与许可差异](../../data/scifact.md)保留原作者、镜像及历史论文之间尚未统一的标签。

| 项目 | BM25 | MiniLM |
| --- | --- | --- |
| 输入文本 | 标题+换行+摘要 | 相同原始字符串 |
| 表示 | 小写ASCII词项、固定21停用词、不词干化 | 官方WordPiece、384维句向量 |
| 评分 | Lucene BM25，k1=1.5、b=0.75 | attention-mask均值池化、L2归一化、余弦 |
| 文本覆盖 | 标题与摘要的完整输入字段 | 右截断到256 tokens，包含特殊tokens |
| 检索 | 全库精确排序 | 全库精确排序 |
| 输出 | 正分候选最多10条 | 不过滤负分，前10条 |

两者均按分数降序、字符串文献ID升序处理同分，并排除query/doc同ID；本数据没有这种ID重叠。BM25本次所有查询都有10个正分结果，所以不存在用零分补位的差异。

MiniLM选用 `sentence-transformers/all-MiniLM-L6-v2` 的[固定官方revision](../../data/minilm.md)，未量化ONNX、CPU单线程、batch16。配置在首次语义运行前提交为 `ded2c97`；BM25历史基线在 `3838e2c`。本项目没有SciFact微调、模型候选筛选或test调参。模型预训练包含S2ORC/SPECTER，具体与SciFact重叠未核实，不能声称已验证无污染零样本。

## 配对结果

全部300条查询逐ID配对，以下差值均为MiniLM减BM25；持平容差为 `1e-12`。

| 指标 | MiniLM提高 | 持平 | MiniLM下降 |
| --- | ---: | ---: | ---: |
| nDCG@10 | 60 | 163 | 77 |
| Recall@10 | 30 | 243 | 27 |

| 诊断 | BM25 | MiniLM |
| --- | ---: | ---: |
| 首位文献在qrels中相关 | 168 | 151 |
| 前10完整召回已标注相关文献 | 229 | 232 |
| 部分召回 | 14 | 6 |
| 零召回 | 57 | 62 |
| 找回的qrel文献对 | 261 | 265 |

MiniLM找回的标注对更多、完整召回查询更多，与宏平均Recall略低并不矛盾。宏平均给每条查询相同权重：只有1篇相关文献时漏掉它，Recall减少1；有5篇相关文献时漏掉1篇，Recall减少0.2。若改用总命中对数除339的微平均，BM25为0.76991、MiniLM为0.78171，排序会反转。这是另一种权重定义，不能替代本报告预先固定的宏平均指标。

## 验证与限制

两种方法各有600个逐查询指标与独立 `pytrec-eval-terrier 0.5.11` 完全一致。参考工具使用严格递减序数分数保留本项目排名，避免其原始同分规则改变顺序。每种方法都由独立进程完整重跑并得到字节一致的结果。语义两次推理在OS层禁网；单独测试了实际ONNX签名、mask池化、归一化、CLS/SEP与padding影响。[BM25记录](bm25-reference-check.json)、[MiniLM指标记录](minilm-reference-check.json)、[MiniLM运行记录](minilm-runtime-check.json)。

3,681/5,183篇文献（71.0206%）超过MiniLM的256-token上限，300条查询均未截断；BM25与MiniLM的有效上下文覆盖不同。没有做长度、实体分词或预训练重叠消融，不能把差距确定归因于某一因素。未进行显著性检验或跨数据集验证，这些是本固定样本的描述性结果。

qrels并非对全部文献的穷尽人工判断。未标注文献在指标中取零并占据名次，不等于已经证实不相关。本项目未做证据句抽取、全文实验质量评价或科学结论裁决，也未测量延迟、内存或能耗差异。

## 复现与离线展示

[BM25完整命令](bm25.md)、[MiniLM完整命令](minilm.md)分别说明固定数据、模型和依赖。基础检索无须语义依赖；完整测试安装 `semantic` extra。运行和数据获取分开，已有快照不重复下载。

```bash
uv sync --frozen --extra semantic
uv run --frozen --extra semantic pytest -q
uv run --frozen --extra semantic python scripts/check_evaluation.py \
  --dataset data/local/scifact --result reports/scifact/bm25.json
uv run --frozen --extra semantic python scripts/check_evaluation.py \
  --dataset data/local/scifact --result reports/scifact/minilm.json
uv run --frozen --extra semantic python scripts/build_comparison.py
```

最后一条只读取仓库中的已冻结结果，生成[配对JSON](comparison.json)和[单文件HTML](comparison.html)，不需要原始语料、模型或网络。HTML可下载后直接用浏览器打开，支持按指标筛选改善/持平/下降、按查询ID选择并查看两套排名。默认展示全部查询；原始分数只用于各自方法内部排序。

[展示验收记录](comparison-validation.json)保存127项测试、独立审查、实际Chrome筛选/下载/键盘/窄屏检查，以及生成文件指纹。浏览器检查由本机HTTP载入页面后断网执行交互；未直接测试file URL。下载的JSON与完整配对结果一致，CI重新生成JSON/HTML并检查是否有差异。

离线展示只呈现保存的实验结果，不运行新的模型检索。原始数据、模型权重、私有会话和账户信息均不进入公共发布包。源码和原创测试材料采用MIT；第三方依赖、数据和模型各自的条款见[第三方说明](../../THIRD_PARTY_NOTICES.md)。
