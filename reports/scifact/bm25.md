## 复现

```bash
uv sync --frozen
# 初次运行需要先按 data/scifact.md 获取固定数据；已有快照不要重复下载。
mkdir -p reports/local
uv run --frozen python -m paper_evidence_lab evaluate \
  --dataset data/local/scifact > reports/local/bm25.json
uv run --frozen python scripts/check_evaluation.py \
  --dataset data/local/scifact --result reports/local/bm25.json
```

配置：标题、换行、摘要拼接；ASCII `[a-z]+` 小写分词，固定 21 个停用词，不做词干化，保留重复查询词。BM25S 0.3.13、NumPy 2.4.6、Python 3.11.14；Lucene BM25 `k1=1.5,b=0.75`，float32。完整配置及实现文件哈希在结果 JSON 中。该配置不是 BEIR 原论文 Anserini 基线的逐项复刻，本报告不拿不同配置的论文成绩作优劣结论。

全体正分候选按分数降序、字符串 ID 升序排序后取 10；不补零分文档；排除查询/文档同 ID（本数据实际没有此重叠）。M0 展示接口仍限 1–5，评测使用独立 top-10 接口。本次每条查询都返回 10 个正分候选。

nDCG 使用 trec_eval 的线性 gain：`rel/log2(rank+1)`，以理想前10排序归一化。Recall 分母是该查询的全部已标注相关文档。全部 300 条查询参加宏平均，空结果计零。未标注文档在指标中得零，但占据排名位置；这不代表它被人工确认不相关。[BEIR 评测实现](https://github.com/beir-cellar/beir/blob/ef83d29307061c65d04b035b4f4e7c18bd8374af/beir/retrieval/evaluation.py)、[trec_eval nDCG](https://github.com/usnistgov/trec_eval/blob/v9.0.8/m_ndcg_cut.c)。

独立参考 `pytrec-eval-terrier 0.5.11` 对照 600 个逐查询指标，最大绝对误差 **0.0**，见[校验记录](bm25-reference-check.json)。传入严格递减序数分数来保留已确定的排名，因为 trec_eval 自身的原始同分规则与本项目不同。此处验证指标公式，不验证 BM25 模型是否科学合理，也不等于重建了同一个检索实现。

同一锁定环境中，两次独立进程完整结果 JSON 字节一致。结果没有运行时间或本地路径；文件哈希标识实现版本。换环境或修改实现后，应核对输入、配置、排名与数值，不能承诺所有硬件逐字节一致。
